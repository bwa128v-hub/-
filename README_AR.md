# تحصيل TAHSEEL — مشروع Flutter

تطبيق عربي لإدارة العملاء والديون والدفعات، مع SQLite محلية وقفل PIN. صُمم للاستخدام اليومي دون اتصال للوظائف المحلية.

## ما يتضمنه هذا الإصدار
- لوحة إجماليات: أصل الديون، المحصّل، المتبقي، وعدد العملاء.
- إضافة وتعديل وحذف العملاء، مع بحث بالاسم أو الهاتف.
- إضافة وتعديل وحذف الديون وتاريخ الاستحقاق وحالة التأخر.
- تسجيل دفعات جزئية مع منع تسجيل مبلغ يتجاوز المتبقي.
- سجل الدفعات وإيصال داخل التطبيق، وحذف الدفعة مع إعادة احتساب المتبقي.
- تقرير بأكبر العملاء مديونية والديون المتأخرة وآخر الدفعات.
- قفل PIN من 4 إلى 8 أرقام، وتغيير الرقم من القائمة.
- تصدير نسخة JSON عبر قائمة المشاركة في الجهاز.
- قاعدة بيانات جديدة تنشأ تلقائياً باسم tahseel.db.

## متطلبات البناء
- Flutter SDK حديث (Dart 3.3 أو أحدث).
- Android SDK وAndroid SDK Platform Tools، وJDK 17.
- اتصال إنترنت عند أول بناء لتنزيل حزم Flutter/Gradle. بعد تنزيل الاعتماديات يمكن تشغيل الوظائف المحلية دون إنترنت.

## بناء APK
1. فك ضغط المشروع.
2. افتح مجلد `tahseel_flutter` في Terminal.
3. نفّذ:
   ```bash
   flutter doctor
   flutter pub get
   flutter build apk --release
   ```
4. الناتج المتوقع بعد نجاح البناء: `build/app/outputs/flutter-apk/app-release.apk`.
5. انسخ APK إلى الهاتف وثبّته. قد تحتاج السماح بالتثبيت من هذا المصدر في إعدادات Android.

## تشغيل على جهاز متصل
```bash
flutter devices
flutter run
```

## اختبار أساسي مقترح
1. افتح التطبيق وأنشئ PIN من 4–8 أرقام، ثم أغلقه وأعد فتحه وتأكد من ظهور شاشة PIN.
2. أضف عميلاً، ثم ديناً له بمبلغ 1000.
3. سجل دفعة 250 وتأكد أن المتبقي 750 في لوحة المؤشرات والديون.
4. حاول تسجيل دفعة أكبر من المتبقي؛ يجب أن يمنعها التحقق.
5. سجل دفعة 750 وتأكد أن الدين أصبح مدفوعاً.
6. افتح الإيصال، وجرّب تصدير نسخة احتياطية.
7. اختبر الحذف والتقارير والبحث.

## حدود مهمة
- قاعدة البيانات محلية على الجهاز ولا تتزامن مع خادم.
- النسخة الاحتياطية الحالية تصدّر JSON للمشاركة. **استيراد/استعادة النسخة الاحتياطية غير منفّذ في هذا الإصدار**.
- الإيصال معروض داخل التطبيق؛ لا توجد طباعة PDF مدمجة بعد.
- إرسال WhatsApp أو SMS غير مدمج في هذا الإصدار. إرسال أي رسالة خارجية يحتاج وسيلة مناسبة واتصالاً/شبكة؛ إدارة الحسابات محلياً لا تحتاج الإنترنت.
- PIN يحمي شاشة التطبيق، لكنه ليس تشفيراً لقاعدة SQLite على مستوى الملف. لا تحفظ بيانات شديدة الحساسية دون إضافة تشفير للقاعدة.
